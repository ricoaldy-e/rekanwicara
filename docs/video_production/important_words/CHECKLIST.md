## Pemeriksaan setiap file sebelum menandai Q dan F

- [ ] Target, induk dan nama cocok kartu; A untuk API dan A untuk ALAMAT tidak tertukar.
- [ ] Semua langkah kartu dilakukan berurutan; kalimat instruksi tidak dibaca sebagai target.
- [ ] Ketukan sesuai sumber; LONG satu potongan, tanpa G tambahan; HAUS satu gerakan/ketukan, tidak dipecah.
- [ ] Kata lengkap mencakup tiga kali pelan dan tiga kali kecepatan biasa sesuai sumber.
- [ ] Bibir, wajah, leher dan gerak tangan terlihat; tidak tertutup teks/tangan atau keluar bingkai.
- [ ] Cahaya, fokus, jarak dan orientasi konsisten; tanpa filter wajah, musik, beep atau dialog samping.
- [ ] Suara target tidak pecah/terpotong/tertutup bising; langkah bisa diikuti melalui gerak dan teks.
- [ ] File MP4/H.264 1080×1920 30 fps dengan audio AAC, dapat diputar utuh oleh pemeriksa lokal.
- [ ] Satu file kanonis per ID; take gagal hanya di _takes; nama file tanpa identitas pribadi.
- [ ] Model menyetujui penggunaan tutorial; penyimpanan dan distribusi lokal mengikuti persetujuan.
