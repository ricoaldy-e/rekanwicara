# Kartu rekam — 24 video tutorial

Baca [panduan produksi](RECORDING_GUIDE.md). Urutan: potongan dahulu, lalu kata utuh. Satu kartu menghasilkan satu file final, bukan satu video per langkah/pengulangan. Belum ada rekaman.

Langkah bernomor disalin verbatim dari Bagian C, kolom Langkah (teks UI), dokumen sumber. Model memperagakan, bukan membacakan kalimat instruksi. Teks langkah ditampilkan satu per satu di luar area bibir.

Urutan setiap kartu: posisi siap sekitar 2 detik → target visual → seluruh langkah bernomor di bawah secara berurutan → posisi akhir sekitar 2 detik. Jeda awal/akhir untuk ruang edit. Jangan menambah narasi atau kata lain.

Potongan: satu rangkaian demonstrasi lengkap sesuai sumber. Kata lengkap: pertahankan tiga pengulangan pelan dan tiga kecepatan biasa. Pengambilan ulang adalah take kerja, bukan aset tambahan.

## 01. kp_tolong_to — TO

- Target pengucapan: **TO**; kata induk: **TOLONG**.
- Jenis: suku kata; pemotongan induk: **to-long**.
- File final rencana: `media/important_words/tolong/syllables/kp_tolong_to.mp4`.
- Rujukan sumber: Bagian C, Tolong, Potongan “to”.

Urutan demonstrasi model:

1. Tempelkan ujung lidah di belakang gigi seri atas, siap untuk “t”.
2. Taruh satu tangan di depan mulut dan satu tangan di leher.
3. Lepas lidah dengan hembusan kecil; leher belum bergetar.
4. Segera bulatkan bibir dengan bukaan sedang dan bersuara “o”; rasakan getar di leher.
5. Gabungkan “t” dan “o” tanpa jeda, sebagai satu ketukan.

Cek take: langkah lengkap/berurutan, tangan tidak menutup bibir, target sesuai label, gerak awal/akhir utuh. Berhenti bila tidak nyaman.

- Target pengucapan: **LONG**; kata induk: **TOLONG**.

- File final rencana: `media/important_words/tolong/syllables/kp_tolong_long.mp4`.

Urutan demonstrasi model:

5. Tahan “ng” sebentar lalu berhenti; jangan menambahkan “g”.
6. Hitung semuanya sebagai satu ketukan.
