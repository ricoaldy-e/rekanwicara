# Tempat video tutorial Kata Penting

Folder ini disiapkan untuk **24 video nyata yang belum direkam**. Tidak ada video dummy.

Mulai dari [panduan produksi](../../docs/video_production/important_words/RECORDING_GUIDE.md),
[kartu rekam](../../docs/video_production/important_words/SHOT_LIST.md), dan
[checklist](../../docs/video_production/important_words/CHECKLIST.md).

Setiap kata mempunyai folder `word/`; tujuh kata juga mempunyai `syllables/`.
HAUS hanya kata lengkap. Nama file final persis mengikuti
[manifest](../../docs/video_production/important_words/video_manifest.csv).
Tiap target menghasilkan satu file final; take kerja ditempatkan di `_takes/`.

`.gitkeep` hanyalah penanda folder, bukan video. Aturan ignore lokal melindungi semua
rekaman/master/hasil ekspor dari Git, termasuk format selain MP4. Hanya README,
`.gitignore` dan `.gitkeep` yang boleh dilacak di sini. Simpan dan periksa video secara
lokal sesuai persetujuan model. Jangan menambahkan rekaman dengan force-add.
